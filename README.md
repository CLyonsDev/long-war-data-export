# Long War data export

This repository has the data export of The Long War Index, https://longwarindex.app/ converted into JSON. This repo will automatically update whenever the index's exported data does.

## Contents

Folders are separated by game version- for example, `data/v5/` holds the rules for game version 5.x. The file `schema.json` in each subfolder gives the structure of the other files in that subfolder.

The file `data/v5/factions/index.json` lists the factions and the data files of each faction. Each path in this file starts at the root of this repository.
